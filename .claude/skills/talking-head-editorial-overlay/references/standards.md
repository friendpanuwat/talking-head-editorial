# มาตรฐานงาน (editorial-overlay)

## Brand (`brand.json`)

คัดลอก `assets/brand.default.json` → `<project>/brand.json` แล้วแก้. ซับ ไฮไลต์ วิดเจ็ต เปลี่ยนตามตอน build.

| คีย์ | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `accent` | `#DDFF45` | สีเดียวของคลิป: คำสำคัญ, กล่องไฮไลต์, ป้ายตัวเลข, ชิป/ปุ่ม MG |
| `navy` | `#14213D` | ตัวอักษร/ไอคอนบนวิดเจ็ตขาว, แท่งกราฟ, tile เข้ม |
| `ink` | `#000000` | (สไตล์นี้แทบไม่ใช้ — ไม่มีการ์ดเต็มจอ) |
| `fonts.key_sans / key_serif / lead / card_sans` | Mitr Bold / Sriracha / Mitr Regular / Mitr SemiBold | ไฟล์ .ttf — path อิงจาก brand.json แล้วจึง assets/ |
| `sfx_db` | `-17` | ระดับแทร็กเสียงประกอบทั้งหมด (ผู้ใช้ให้เบาลงจาก −11) |

accent ต้องอ่านออกบนพื้นดำและบนหน้าคนพูด (สีสว่างอิ่ม). ฟอนต์ไทยต้องรองรับสระ/วรรณยุกต์ครบ และใช้เชิงพาณิชย์ได้
(Mitr, Sriracha = OFL — ไฟล์ license อยู่ใน `assets/licenses/`; ไอคอน Lucide = ISC).

## ตัวอักษร

| ชั้น | ฟอนต์ | ขนาด | สี |
|---|---|---|---|
| คำนำ `l` | Mitr Regular | 54 | ขาว |
| คำสำคัญ `k` | Mitr Bold, letter-spacing −2 | 146 (statement 170–190) | accent |
| คำสำคัญลายมือ `i` | Sriracha | 150 | accent / ขาว / กรมท่า |
| ไฮไลต์ `hl` | Mitr Bold บนกล่อง accent มุม 12 | 90–120 | ดำ |
| ข้อความในวิดเจ็ต | Mitr SemiBold / Bold | 26–60 | กรมท่าบนขาว, ดำบน accent |

Motion: คำนำ = ลอยขึ้น 16 px + เบลอ 7→0 ใน 0.2 วิ; คำสำคัญ = ย่อ 1.16→1 + เบลอ 14→0 ใน 0.26 วิ; ก้อนหายแบบตัดทันที.
ซับ A-roll มีเงาดำนุ่ม (ไม่มีกล่องพื้นหลัง).

## โซนบนจอ (1080×1920)

- **โซนวิดเจ็ต** (หาจาก grid.jpg + contact sheet ทุกคลิป): ปกติเหนือหัว y ≈ 130 → ยอดหัวสูงสุด − 40 px (ตัวอย่าง 150–540, หัวเริ่ม ~600).
  เผื่อซูม: ซูม 1.10 ดันยอดหัวขึ้น ~30 px. เหนือหัวแคบ (< 250 px) → ข้างลำตัวซ้าย x 40–330 และย่อวิดเจ็ต. อย่าวางอะไรเหนือ y 120.
- ใบหน้า: ห้ามมีอะไรทับ. ซับ: ระดับอก (ค่าเริ่ม top 1150) กว้าง ≤960 สูง ≤420.
- ล่าง 300 px และขวา 140 px: เว้นให้ UI ของ TikTok/Reels.

## กล้องและวิดเจ็ต

- **ไม่เกรดสี ไม่เบลอ ไม่หรี่** — คลิปต้นฉบับคมและเห็นหน้าตลอดทั้งคลิป; ไม่มีการ์ดเต็มจอ.
- ซูมตัดชน 1.05–1.10 ที่คำใหญ่, กลับ 1.0 ที่ก้อนถัดไป. ห้ามซูมพุ่ง/หมุน/whip/กลิตช์.
- วิดเจ็ตเข้า = สปริง (scale .78 + ขึ้น 46 px, BOUNCE 0.48 วิ); ออก = ย่อ .86 + จาง 0.16 วิ. ทีละชิ้น, ≤ ~600×380, ไม่มี backdrop-filter.

## เสียง

ความดังรวม **−14 LUFS ±0.5, peak ≤ −1.5 dBTP** (pipeline ทำให้). เสียงประกอบสังเคราะห์จาก `scripts/sfx.py` (ไม่มีลิขสิทธิ์).

| จังหวะ | เสียง | dB |
|---|---|---|
| คำสำคัญ | `softswish` (ผ่าน `keyHit`) | −22 |
| วิดเจ็ตเข้า | `softswish` (อัตโนมัติจาก `widget`) | −25 |
| tile / bubble / chip เด้ง | `pop` / `pop_hi` / `pop_lo` อัตโนมัติ | −25 ถึง −27 |
| ขีดฆ่า / เส้นกราฟ | `swipe` อัตโนมัติ | −24 |
| กากบาท / x | `stamp` | −21 |
| ลูกศรเข้าเป้า / ชิปตก | `thud` | −16 / −22 |
| ปิดคลิป | `sub` | −16 |
**เสียงประกอบแบบเบาและไม่จุกจิก (ผู้ใช้สั่ง):** ตอน mix เอนจินตัดเสียง `pop` / `pop_hi` / `pop_lo` / `tick` ทิ้งทั้งหมด
(ภาพเด้งก็พอ) และในทุกช่วง 0.9 วินาทีเหลือเสียงเดียวที่สำคัญที่สุด (`sub` > `stamp`/`thud` > `whoosh` > `swipe` > `softswish`) —
`calmSfx()` ใน engine_head.html; ตารางด้านบนคือเสียงที่ "ขอ" ได้ ไม่ใช่ทุกเสียงที่จะได้ยิน.
**ไม่รบกวนเสียงพูด (ผู้ใช้สั่ง — กติกาเดียวกันทุกสกิล):** เสียงประกอบเบากว่าเสียงพูดเสมอ และตอน mix `scripts/mix_sfx.sh` หรี่แทร็กเสียงประกอบลงอีก ~6 dB ขณะคนพูด (sidechain) แล้วค่อยกลับตอนเว้นจังหวะ.
**ไม่ใช้** glitch, boing, womp, sparkle. เพลงประกอบไม่ใส่ (ลิขสิทธิ์) — แนะนำให้ผู้ใช้เลือกในแอปตอนโพสต์.
