# Talking-Head Editorial — คู่มือการใช้งาน

ตัดต่อคลิปพูดหน้ากล้องแนวตั้ง (TikTok / Reels / Shorts) สไตล์ editorial แบบงานรับตัดต่อมืออาชีพ
ด้วย Claude — สั่งจากมือถือได้ ไม่ต้องติดตั้งโปรแกรม

**ได้ 2 สไตล์ในชุดเดียว** — เลือกได้ทุกครั้งที่สั่ง
| สกิล | หน้าตา |
|---|---|
| `talking-head-editorial` | สลับระหว่างหน้าคุณกับการ์ดเต็มจอสั้น ๆ (การ์ดขาว / ดำ / กรมท่า, โปสเตอร์ครีม, หน้าคุณย่อเป็นการ์ด) |
| `talking-head-editorial-overlay` | เห็นหน้าคุณตลอดทั้งคลิป มีวิดเจ็ตกราฟิกชิ้นเล็กเด้งขึ้นเหนือหัว |

**ได้อะไร (ทั้ง 2 สไตล์)**
- ซับภาษาไทยขึ้นทีละคำตามเสียง แต่ละก้อนมีคำสำคัญคำเดียวตัวใหญ่ (ตัวหนา Mitr หรือลายมือ Sriracha) สี accent สีเดียว
- ซูมตัดชนที่คำสำคัญ
- motion graphics (การ์ดแบน มุมมน ไอคอนเส้น) ที่ออกแบบใหม่ให้ตรงกับสิ่งที่คุณพูดในคลิปนั้น — หรือใช้รูป / คลิปที่คุณส่งมาแทนได้
- เสียงประกอบเบา ๆ ไม่จุกจิก และปรับเสียงทั้งคลิปให้ดังมาตรฐานโซเชียล (−14 LUFS)
- ไฟล์ MP4 1080×1920 พร้อมโพสต์

**ไม่ทำ:** ปรับสีวิดีโอ · ใส่เพลงประกอบ (เลือกเพลงในแอปตอนโพสต์ได้)

---

## 1. สิ่งที่ต้องมี

- บัญชี **Claude** แพ็กเกจที่ใช้ **Claude Code** ได้ (เช่น Pro หรือ Max)
- บัญชี **GitHub** (สมัครฟรีที่ github.com)
- repo นี้อยู่ในบัญชี GitHub ของคุณ (ตั้งเป็น Private)

## 2. ตั้งค่าครั้งแรก (ทำครั้งเดียว)

**ขั้นที่ 1 — เอา repo มาไว้ในบัญชีของคุณ**
เปิดลิงก์ repo ที่ได้รับ → กด **Use this template** → **Create a new repository** →
ตั้งชื่อ (เช่น `my-editorial`) → เลือก **Private** → **Create repository**

**ขั้นที่ 2 — เชื่อม GitHub กับ Claude**
เปิด https://claude.ai/connect-github → ล็อกอิน GitHub → อนุญาตให้ Claude GitHub App เข้าถึง repo ที่สร้างในขั้นที่ 1

**ขั้นที่ 3 — ตั้งค่าอินเทอร์เน็ตของเครื่อง Claude**
เปิด Claude Code (แอป Claude หรือ https://claude.ai/code) → เลือก repo ของคุณ →
กดเมนู environment (ชื่อ environment ด้านบน) → **Edit** → **Network access** → เลือก **Full** (แนะนำ)

ถ้าเลือก **Limited** ต้องเพิ่มโดเมนเหล่านี้ใน **Allowed domains** (ติ๊ก Allow package managers ไว้เหมือนเดิม):
```
drive.google.com
drive.usercontent.google.com
huggingface.co
```
(`huggingface.co` ใช้โหลดตัวจับเวลาคำพูดให้ซับตรงเสียงระดับคำ — ถ้าไม่ได้เพิ่ม งานยังทำได้ แต่ซับอาจคลาดจากเสียงมากกว่า)

เสร็จแล้ว ต่อไปสั่งงานได้เลยทุกครั้ง

## 3. วิธีสั่งตัดต่อ

1. อัปโหลดคลิปขึ้น **Google Drive** → แชร์ → ตั้งเป็น **"ทุกคนที่มีลิงก์"** → คัดลอกลิงก์
2. เตรียม **บทพูดพร้อมเวลา** — Claude ฟังเสียงไม่ได้ จึงต้องมีบทพูดเสมอ
   - ไฟล์ .srt หรือ
   - ข้อความแบบนี้ (คัดจากซับอัตโนมัติของ CapCut ได้):
     ```
     00:00 เวลาลูกค้าทักมาถามรายละเอียดสินค้า
     00:01 แล้วก็หายไปเนี่ย
     00:02 หลายคนก็อาจจะคิดว่า
     ```
3. (ไม่บังคับ) มี **รูปหรือคลิปประกอบ** ของคุณเอง — แนบมาด้วยหรือส่งลิงก์ Drive; ถ้าไม่มี Claude จะทำ motion graphics ให้
4. เปิด Claude Code → เลือก repo ของคุณ → พิมพ์ `/effort high` แล้วส่งก่อน 1 ครั้ง
   (ตั้งให้ Claude คิดละเอียดขึ้น — ตัดต่อทั้งคลิปควรใช้ระดับ high งานจะออกมาดีกว่า)
   จากนั้นพิมพ์:
   ```
   ตัดต่อคลิปนี้ตาม skill talking-head-editorial
   <ลิงก์ Google Drive>
   <บทพูดพร้อมเวลา>
   ```
   ถ้าอยากได้แบบเห็นหน้าตลอด ให้พิมพ์ `talking-head-editorial-overlay` แทน
5. รอรับคลิปได้เลย — Claude ทำให้ครบรวดเดียว ไม่ต้องตอบอะไรระหว่างทาง (คลิป 40 วินาทีใช้ประมาณ 10 นาที)
6. ได้คลิป `edit.mp4` ในแชท (ไฟล์เล็ก ดูบนมือถือได้ทันที)
   พร้อม **ลิงก์ดาวน์โหลดไฟล์คุณภาพสูงสำหรับโพสต์จริง** — ส่งมาให้เอง ไม่ต้องพิมพ์ขอ
   (เปิดลิงก์ขณะล็อกอิน GitHub บัญชีเดียวกับเจ้าของ repo)

## 4. ขอแก้

บอกเป็นวินาที เช่น
```
วินาทีที่ 12 ซับผิด "โปรโมชัน" → "โปรโมชั่น"
การ์ดวินาทีที่ 20–24 อยากให้เป็นรูปกระปุกออมสินแทน
```
Claude จะแก้เฉพาะจุดแล้วส่งคลิปใหม่

ขอแก้จุดเล็ก ๆ แบบนี้ ใช้ `/effort medium` ได้ (พิมพ์ส่งก่อนข้อความขอแก้) — เร็วกว่าและประหยัดโควตาการใช้งาน

## 5. ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| `DOWNLOAD FAILED` / โหลดคลิปไม่ได้ | ตรวจว่าแชร์ไฟล์เป็น "ทุกคนที่มีลิงก์" และทำขั้นที่ 3 ของการตั้งค่าแล้ว |
| `WHISPER UNAVAILABLE` | ตัวจับเวลาคำพูดโหลดไม่ได้ — งานยังทำต่อได้ แต่ซับอาจคลาดเล็กน้อย; เลือก Network access = Full แล้วสั่งใหม่ถ้าอยากได้เวลาแม่นขึ้น |
| `NO GIT REPO` | เริ่มแชทใหม่โดยเลือก repo ของคุณก่อนพิมพ์สั่ง |
| ซับคลาดจากเสียงเล็กน้อย | บอกวินาทีที่คลาดให้ Claude แก้ |
| ลิงก์ไฟล์ HQ เปิดไม่ได้ | ล็อกอิน GitHub บัญชีเจ้าของ repo ก่อนเปิดลิงก์ |
