# Card library

การ์ดแต่ละใบต้อง **เล่าความหมายของประโยค** ไม่ใช่แค่ตกแต่ง — ถามตัวเองว่า "ถ้าปิดเสียง การ์ดนี้ยังสื่อไหม".
ทุกสูตรด้านล่างมีตัวอย่างจริงใน `examples/timeline_mg.js` / `timeline_broll.js` (ระบุชื่อ C1…C11 ในคอมเมนต์).

**การ์ดและ MG ต้องทำใหม่ให้คลิปนั้น (ผู้ใช้สั่ง)** — C1…C11 คือการ์ดที่ออกแบบให้คลิปตัวอย่าง: ใช้ดูระดับงาน ภาษาภาพ
และวิธีใช้ฟังก์ชัน **ไม่ใช่เทมเพลตให้เปลี่ยนคำ**. ทุกคลิปให้คิดใหม่ทีละประโยค:
1. ประโยคนี้พูดถึงอะไร — ของ คน หรือการกระทำอะไรที่ถ้าปิดเสียงแล้วยังเข้าใจ (จากคำพูดของคลิปนี้ ไม่ใช่จากคลิปก่อน)
2. อะไรควรเกิดตรงคำสำคัญ (ร่วง, ตก, ส่าย, ขีดฆ่า, ล็อก, หาย …)
3. ประกอบจากชิ้นใน kit (`tile`, `panel`, `chip`, `bars`, `target`, ไอคอน Lucide …) ในภาษาภาพเดิม
สไตล์ไม่เปลี่ยน: ชนิดการ์ด ฟอนต์ accent สีเดียว ขนาด และการเคลื่อนไหวตามไฟล์นี้และ `standards.md` คงเดิมทุกข้อ.

## 1. การ์ดตัวอักษร (ใช้ได้ทุกคลิป)

| ชนิด | หน้าตา | ใช้กับ | ตัวอย่าง |
|---|---|---|---|
| **ขาว ประกอบคำ** | พื้นขาว ตัวกรมท่า, คำขึ้นทีละวลีแล้วค้าง, คำสุดท้ายเป็น `hl` + `strike` ได้ | ประโยคหักมุม / "ไม่ใช่ X" | C5 |
| **ขาว คำเดียว** | คำนำเล็ก + คำใหญ่ `iw` กรมท่า; เติมเอฟเฟกต์ความหมายได้ (เช่น "หายไป" เบลอจางหาย) | จังหวะ punch 0.6–1 วิ | C1 |
| **กรมท่า สีไล่** | พื้น navy, คำนำขาว + คำใหญ่ `kw` `{wipe: true}` | คำถาม / ประโยคที่อยากให้ค้างในหัว | C6 |
| **frame()** | หน้าคนพูดย่อเป็นการ์ดมุมมนบนพื้นครีม ข้อความกรมท่าด้านบน | ประโยคที่อยากให้เห็นคนพูด + ข้อความพร้อมกัน (1 ครั้ง/คลิป) | F1 |

## 2. การ์ดภาพ (เมื่อผู้ใช้ส่ง B-roll มา)

- **ภาพพื้นดำ / ตัดพื้นหลัง** → `card(bg:'black')` + `pic(..., 'left:0;top:40px;width:1080px;height:1440px')` เต็มความกว้าง,
  ข้อความ `aroll` วางล่าง (top ~1210–1300) ทับลำตัวในภาพ. (C2, C3, C7, C9, C10, C11 ใน timeline_broll.js)
- **ภาพทั่วไป / ภาพถ่าย** → โปสเตอร์ครีม: `curl()` + `pic()` ในกรอบมุมมน 740×986 ที่ top 430 + เงา,
  หัวเรื่อง `iw` กรมท่าด้านบน, คำปิด `hl` ด้านล่าง. (C4, C8)
- **คลิปวิดีโอ** → `prep_broll.sh` แล้ว `clip(c, name, t, 'left:0;top:0;width:1080px;height:1920px')` เต็มจอ + ข้อความ `aroll`.
- เลือกภาพให้ตรงประโยค; ภาพที่ไม่เข้ากับประโยคไหนเลยไม่ต้องใช้ (บอกผู้ใช้ว่าไม่ได้ใช้ภาพไหน).
- รายการ/ทางเลือกในประโยค → `pill()` ซ้อนขึ้นทีละอันตามเสียง (C3).

## 3. Motion graphics (เมื่อไม่มี B-roll) — Flat × Glow

ภาษาภาพ:
- **Flat (การ์ดแบน)** = รูปทรงแบน มุมมนใหญ่ (radius ≈ 26% ของขนาด), ไอคอนเส้น Lucide, ทุกอย่างเด้งเข้าแบบ overshoot (`BOUNCE`),
  ไล่เวลาทีละชิ้น 0.1–0.2 วิ, มี "เรื่องเล็ก ๆ" เกิดขึ้นในการ์ด (ราคาเด้ง, กราฟร่วง, เคอร์เซอร์ลังเล, ลูกศรเข้าเป้า).
- ไม่ใช้บาร์โค้ด (ผู้ใช้ไม่เอา); มุมกระดาษม้วน `curl()` ใช้ได้.
- **Glow (พื้นเรืองแสง)** = พื้นการ์ดดำมีแสงฟ้า/ม่วงไหลช้า + ตารางจุดจาง (`mood()`), กล่องกระจกฝ้า (`bg: 'glass'`, `panel style 'glass'`), ลอยขึ้นลงเบา ๆ.
- ชิ้นหลัก 1 ชิ้น (ขาว/accent, ใหญ่ 300–560 px) + ชิ้นรอง 1–3 ชิ้น (glass, 140–200 px) รอบ ๆ. ไม่เกิน 5 ชิ้นต่อการ์ด.
- ข้อความของการ์ดยังเป็นตัวเอก: MG อยู่ y 150–1100, ข้อความ y 1200–1600.
- ทุก MG ต้องมี "จังหวะตรงคำ": อย่างน้อย 1 เหตุการณ์ตรงกับเวลาคำสำคัญ (punch, wobble, cross, hit).

ตัวอย่างวิธีคิดจากคลิปตัวอย่าง (`examples/timeline_mg.js`) — ดูว่าความหมายกลายเป็นภาพยังไง แล้วคิดภาพของคลิปใหม่เอง
อย่ายกสูตรไปใช้ทั้งชุด; ประโยคที่ความหมายคล้ายกันก็ให้หาภาพที่ตรงกับคำพูดของคลิปนั้นที่สุด:

| ความหมายของประโยค | สูตร MG | ตัวอย่าง |
|---|---|---|
| แพง / ราคา / เงิน | `tile('tag', 300 ขาว)` กลาง + `banknote`, `wallet` แบบ glass รอบ ๆ; ที่คำ "แพง" → `punch` + `ripple` | C2 |
| ลูกค้าถาม / สงสัย / ลังเล | มือถือ `panel glass` + `bubble` คำถามจากบท + tiles `package`, `star`, `circle-help` (accent), `shopping-cart` + `pill` รายการ | C3 |
| ยอดตก / ลูกค้าน้อยลง | โปสเตอร์ครีม + `panel` ขาว: tile `store`, `skel`, `bars(..., {to, tTo})` ร่วงตรงคำ + `trend` แดงลง | C4 |
| ไม่กล้าจ่าย / ลังเลจะซื้อ | `panel` หน้าชำระเงิน: สินค้า + `skel` + ปุ่ม accent "ชำระเงิน"; `cursor` เข้าไปค้างที่ปุ่ม (`punch`) แล้วถอยออก ไม่คลิก | C7 |
| คุณภาพ / รีวิว / ไม่มั่นใจ | โปสเตอร์ครีม + `panel`: tile `package` navy ใหญ่ + `circle-help` accent + `stars(5, 2)` | C8 |
| ลดราคาแล้วก็ไม่ซื้อ | tile `shopping-cart` ใหญ่ + ชิป accent "ลดราคา"/"ลดเพิ่ม" ตกลงมาเด้ง; ที่คำปฏิเสธ → `wobble` + tile `x` แดง | C9 |
| สิ่งที่ไม่ควรทำ / ขั้นตอน | `num(1)` + หัวเรื่อง + tile ใหญ่ของสิ่งนั้น (`badge-percent`) → `cross()` + `wobble` ตรงคำ | C10 |
| แก้ถูกจุด / เป้าหมาย / สรุป | `target()` ลูกศรเข้ากลางตรงคำ + `lightbulb`, `search` แบบ glass, `sfx('sub')` | C11 |
| หายไป / เงียบ | tile `ghost` navy บนการ์ดขาว + คำ `iw` ที่เบลอจางหาย | C1 |

แนวคิดอื่นที่ทำจาก kit ได้ (ยังไม่มีในตัวอย่าง — preview ให้ละเอียดก่อนใช้):
เวลา/รอ → `hourglass`/`clock` + `float`; แจ้งเตือน → `panel` เล็ก + `bell` เลื่อนลงจากบน; เช็กลิสต์ → `panel` + แถว `check`
ติ๊กทีละข้อ (`popIn`); เปรียบเทียบ → สอง `panel` ซ้าย-ขวา + `scale`; ความเชื่อมั่น → `shield-check` + `ripple`;
ไอเดีย → `lightbulb` accent + `sparkles`. ไม่ใส่ตัวเลข/ราคาที่ผู้พูดไม่ได้พูด.
