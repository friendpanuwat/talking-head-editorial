# คลังวิดเจ็ต (โค้ดจริงใน `examples/timeline_example.js` — ค้นหัวข้อ `W1 ·` ถึง `W14 ·`)

**วิดเจ็ตต้องทำใหม่ให้คลิปนั้น (ผู้ใช้สั่ง)** — W1–W14 คือวิดเจ็ตที่ออกแบบให้คลิปตัวอย่าง: ใช้ดูระดับงาน ภาษาภาพ และวิธีใช้ฟังก์ชัน
**ไม่ใช่เทมเพลตให้คัดลอกแล้วเปลี่ยนเวลา/ข้อความ/ไอคอน**. ทุกคลิปให้ออกแบบวิดเจ็ตใหม่ตามหัวข้อ "ออกแบบวิดเจ็ตใหม่" ด้านล่าง
จากคำพูดของคลิปนั้น; สไตล์ (Jitter แบน การ์ดขาว ไอคอนเส้น accent สีเดียว ขนาด โซน การเคลื่อนไหว) คงเดิมทุกข้อ.
ตารางนี้คือตัวอย่างวิธีคิด — ดูว่าความหมายของประโยคกลายเป็นภาพและเหตุการณ์ตรงคำยังไง. ตัวอย่างออกแบบสำหรับโซนเหนือหัว y ≈ 150–540 (หัวเริ่ม ~y 600).

## ออกแบบวิดเจ็ตใหม่ (ทุกคลิป)

ทีละประโยคที่จะมีวิดเจ็ต: (1) พูดถึงอะไร — ของ คน หรือการกระทำที่ถ้าปิดเสียงแล้วยังเข้าใจ (จากคำพูดของคลิปนี้)
(2) อะไรเกิดตรงคำสำคัญ (3) ประกอบจากชิ้นใน kit ในภาษาเดิมด้านล่าง. สองคลิปที่พูดเรื่องคล้ายกันก็ต้องคิดภาพจากประโยคของคลิปนั้น.

ภาษาเดียวกัน (Jitter แบน): **ชิ้นหลัก 1 ชิ้น** (การ์ดขาว / tile / ชิป) + ชิ้นรอง ≤ 2 + การเคลื่อนไหวที่สื่อความหมาย
(เด้ง, ตก, ส่าย, ร่วง, วาด, กากบาท, ล็อก). มุมมนใหญ่, เงานุ่ม, ไอคอนเส้น Lucide, accent / ขาว / กรมท่า เท่านั้น (+แดงเมื่อเป็นลบ).
ข้อความ ≤ 3 คำ. ขนาด ≤ ~600×380 และอยู่ในโซนวิดเจ็ตทั้งหมด. ห้าม backdrop-filter, glass, บาร์โค้ด, กลิตช์, อีโมจิ.
